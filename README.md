# ⛈️ Clima Turbo 2.0 - Deep Ocean Edition

Uma estação meteorológica futurista desenvolvida com **React** e **Vite**. O projeto consome a OpenWeatherMap API para exibir dados climáticos globais com uma interface imersiva "Sci-Fi", inspirada em dashboards de comando militar e oceanografia.

![Project Preview](public/vite.svg) 
*(Dica: Tire um print da tela inicial e do dashboard e coloque aqui depois)*

## 🚀 Tecnologias Utilizadas

* **Core:** React.js, Vite
* **Estilização:** Tailwind CSS (Glassmorphism & Neon Effects)
* **Animações:** Framer Motion, React Parallax Tilt (Efeito 3D)
* **Mapas:** Leaflet & React-Leaflet (Custom Dark Mode)
* **Gráficos:** Recharts (Area Charts interativos)
* **API:** OpenWeatherMap (Forecast 5 days)
* **Ícones:** Phosphor React

## ✨ Funcionalidades

* **Interface Sci-Fi Viva:** Tela inicial com radar animado e tags de monitoramento global.
* **Busca Inteligente:** Localização de qualquer cidade do mundo com feedback visual.
* **Fundo Dinâmico:** Vídeos em 4K que mudam conforme o clima (Chuva, Sol, Neve), com filtro de cor "Navy Blue".
* **Dashboard 3D:** Cards que reagem ao movimento do mouse (Tilt Effect).
* **Mapa Tático:** Visualização de satélite com filtro de cores invertidas para modo noturno.
* **Gráficos de Previsão:** Projeção de temperatura para os próximos 5 dias.
* **Ciclo Solar:** Horários precisos do nascer e pôr do sol.

## 🔧 Como rodar localmente

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/seu-usuario/clima-turbo-2.0.git](https://github.com/seu-usuario/clima-turbo-2.0.git)
    ```
2.  Instale as dependências:
    ```bash
    npm install
    ```
3.  Crie um arquivo `.env` na raiz e adicione sua chave:
    ```env
    VITE_API_KEY=sua_chave_aqui
    ```
4.  Rode o projeto:
    ```bash
    npm run dev
    ```
